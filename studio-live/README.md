# AI Business Studio Live — версия 2 (живая генерация)

Вписываете любой бизнес («Bubble tea kiosk near a university in Cebu City») → 4 ИИ-команды прямо на экране пишут решение с нуля: бизнес-план, анализ локации, портреты клиентов, финмодель с ползунками, бренд и логотип, продукты с маржой, креативы и рекламу, сценарии видео для Vivix, план запуска, вакансию и живого чат-бота. Страница перекрашивается в цвета придуманного бренда.

## Как работает

- Текст пишет Claude через возможность `sample` опубликованной страницы claude.ai: расход идёт с аккаунта того, кто открыл страницу, первый запуск спрашивает разрешение.
- Сначала Strategy team придумывает название, концепцию и бренд (~20–40 с), затем Location, Finance и Marketing работают параллельно. Полная сборка — около 1–2 минут.
- Разделы появляются по мере готовности, в карточках команд виден «живой» поток ответа и счётчик токенов, сверху — таймер.
- Чат-бот в конце отвечает вживую, по данным только что созданного плана.
- Если Claude недоступен (страница открыта не на claude.ai), предлагается готовый пример (Kape Apo, Давао).

## Ограничения

- Видео в этой версии не рендерятся: опубликованная страница не может обращаться к Vivix. ИИ пишет готовые промпты с кнопкой «Copy prompt» — их можно вставить в Vivix.
- Если у команды ошибка (лимит, сбой), на её карточке появится «Try again».

Код — один файл `index.html`.
