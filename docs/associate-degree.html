Associate Degree · 2 years

Start with an Associate Degree. Keep the Bachelor’s option open.

Choose Software Development, Computer Graphics and Design, or Digital Marketing and Communication. Study for 2 years, complete the graduation project and final exams, and earn the Associate Degree when you meet the requirements.

  • 2 years of study + final exams
  • Accredited by MoEYS
  • Official degree diploma
  • 1 of 3 majors
Free consultation
Who it’s for

Start working faster — or keep going

Best if you want to start working faster, or want to keep opportunities open if you did not pass the BAC II exam: after graduating with an Associate Degree you may continue to a Bachelor’s Degree.

Next step: want to continue?

Stay in the same major for Years 3–4 of the Bachelor of Computer Science pathway.

  1. Years 1–2 — Associate Degree: graduation project and final exams
  2. Years 3–4 — continue in the same major
  3. Thesis — earn the Bachelor of Computer Science
Curriculum

Three majors

This programme is accredited by the Ministry of Education, Youth and Sport and leads to an official degree diploma upon completing the full programme and degree requirements.

Software Development

Learn to build websites, mobile apps and software that people can use.

Year 1

  • English for IT
  • Introduction to Information Technology
  • Digital Literacy
  • IT Essentials with CISCO certificate exam
  • Python Core
  • Microsoft .NET and programming C#
  • Database Theory and MS SQL programming
  • Entity Framework Core
  • Basic Entrepreneurship

Year 2

  • HTML and CSS in web development
  • JavaScript Programming Language
  • Web Application Development with ASP.NET Core
  • Term project .NET
  • Developing Web applications using Python
  • Cloud Solutions for applications development
  • Web applications development with PHP and MS SQL
  • Development Mobile Apps Using React Native
  • Web development team project
