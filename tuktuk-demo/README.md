# ТукТук Киев AI Studio — вариант 5: сервис туктуков в Киеве

Готовое демо на русском: 8 ИИ-агентов собирают сервис коротких поездок на туктуках, в два раза дешевле такси.

## Как показать

`index.html` в Chrome → **F** → **Enter** → стрелки **→ / ←**. `index.html#results` открывает результаты сразу.

## Слайды

1. Бизнес-план, аудитория, SWOT.
2. **Цена против такси** — калькулятор с ползунком расстояния и сравнение типичных поездок.
3. Район запуска: Позняки–Осокорки, Оболонь, Подол, Печерск (схема Киева с Днепром).
4. Клиенты · 5. Финмодель · 6. Бренд · 7. Тарифы.
8. Видео Vivix (туктук на бульваре, рилс у метро, водитель Сергей говорит по-русски).
9. Рекламный ролик на 15 секунд · 10. Креативы · 11. План запуска · 12. Чат-бот-диспетчер.

Цены такси, аренда и все цифры — иллюстративные оценки, меняются в `data.js` (раздел `taxi` — тарифы для калькулятора). Требования к лицензии на пассажирские перевозки и регистрации трициклов нужно проверить отдельно.

Фото-образец туктука, по которому Vivix рисовал машину, в репозиторий не добавлено.
