# LunasCare Branch Planner — вариант 3: второе отделение аптеки в Давао

Готовое демо (как первый вариант с кофейней) для кейса «аптека в Toril, Davao City открывает второе отделение». 8 ИИ-агентов изучают первую аптеку, выбирают район для филиала №2 и собирают весь пакет запуска.

## Как показать

Откройте `index.html` в Chrome → **F** (полный экран) → **Enter** (запуск агентов) → стрелки **→ / ←**. `index.html#results` открывает результаты сразу.

## Слайды

1. **Business plan** — концепция филиала, аудитория, SWOT и «что ИИ узнал из данных Toril» (транзакции, средний чек, выручка, маржа).
2. **Location analysis** — 4 района (Mintal, Catalunan Grande, Calinan, Ulas) по 5 факторам, включая «достаточно далеко от Toril, чтобы не забирать клиентов». Карта с первой аптекой и кандидатами. Победитель — Mintal.
3. **Customers** — Lola Remedios (пенсионерка, поддерживающая терапия), Mark (отец троих детей, дженерики), Jenny (Messenger и GCash).
4. **Financials** — бюджет филиала ₱3,3 млн (основное — стартовый товарный запас), окупаемость, ползунки.
5. **Brand** — тот же бренд для нового филиала.
6. **Assortment** — 12 позиций с маржой (дженерики, поддерживающая терапия, Rx, витамины, услуги).
7. **Video** — 3 ролика Vivix: фасад филиала, рилс, фармацевт Ана говорит на камеру (A1).
8. **15-second TV ad** — рекламный ролик Vivix W1 с раскадровкой и финальной плашкой бренда.
9. **Creatives** — посты для Facebook, A/B-реклама, контент-план, карточка Google Maps.
10. **Launch plan** — 90 дней: FDA License to Operate, фармацевт с лицензией PRC, Mayor’s permit, обучение в Toril; вакансия фармацевта.
11. **AI assistant** — чат-бот: наличие, цены, скидка 20% для сеньоров/PWD, Messenger-заказы; не ставит диагнозы и не продаёт антибиотики без рецепта.
12. **Summary**.

## Важно

- Название **LunasCare** и все цифры (продажи Toril, аренда, бюджет) — **примеры для демо**. Замените их в `data.js` на реальные: название аптеки, её показатели, цены.
- На вывесках в сгенерированных видео ИИ иногда рисует «нечитаемый» текст — это особенность видео-моделей.
- Живая генерация видео: `VIVIX_API_KEY=ключ node server.mjs` → http://localhost:3000.
