# ИИ-студия: кофейня «Зерно» — демо для презентации курса «ИИ с нуля до про»

Одна страница, которая на глазах у зала «собирает» бизнес: 7 ИИ-агентов по очереди делают бизнес-план, финмодель, бренд, меню, видео (Vivix), креативы и чат-бота. Всё заготовлено заранее, поэтому показ не зависит от интернета и ничего не сломается.

## Как показать (3 шага)

1. Откройте `index.html` в Chrome (двойной клик) и нажмите **F** — полный экран.
2. Нажмите **«Запустить ИИ ✨»** (или Enter) — агенты отработают за ~12 секунд.
3. Листайте слайды стрелками **→ / ←** или кнопкой **▶ Автопоказ**.

| Клавиша | Действие |
|---|---|
| Enter / Пробел | запустить ИИ-команду; во время анимации — пропустить её |
| → ← ↑ ↓ | следующий / предыдущий слайд |
| F | полный экран |
| R | начать заново |
| клик по видео | включить звук (бариста Аня говорит по-русски) |

Ссылка `index.html#results` сразу открывает готовые результаты без анимации.

## Что внутри

1. **Бизнес-план** — концепция (печатается на глазах), аудитория, SWOT.
2. **Финмодель** — вложения, выручка, окупаемость, график на 24 месяца. Ползунки «средний чек» и «чеков в день» пересчитывают модель вживую — хороший момент для вовлечения зала.
3. **Бренд** — логотип (рисуется анимацией), палитра, слоган, тон.
4. **Меню** — 12 позиций с себестоимостью и маржой.
5. **Видео Vivix** — промо-ролик и рилс (Vivix W1) и говорящая бариста (Vivix A1). Все три сгенерированы настоящим API Vivix.
6. **Креативы** — сторис, посты, баннер, 3 рекламных текста с A/B-прогнозом, контент-план на неделю.
7. **ИИ-бариста** — чат-бот в телефоне: нажмите подсказку или задайте свой вопрос.
8. **Итог** — «с ИИ vs как раньше» и конфетти.

## Поменять тексты и цифры

Всё содержимое — в `data.js`: название, слоган, цены, меню, вложения, ответы бота, валюта (`currency`). Код трогать не нужно. Скорость анимации агентов — константа `STEP` в `app.js`.

## Живая генерация видео (необязательно, для «вау»)

Если хотите сгенерировать видео прямо на сцене:

```bash
VIVIX_API_KEY=ваш_ключ node server.mjs
# открыть http://localhost:3000
```

На слайде «Видео» появится поле: впишите описание ролика → «Сгенерировать вживую». Ролик 6 секунд, генерация обычно занимает около минуты. Без ключа сервер тоже работает — просто без этого поля.

## Перегенерировать заготовленные видео

```bash
export VIVIX_API_KEY=ваш_ключ
node scripts/vivix.mjs world assets/video/hero.mp4 16:9 10 "описание ролика"
node scripts/vivix.mjs avatar /dev/null assets/img/barista.jpg "описание жестов" "Текст, который скажет бариста"
# avatar печатает ссылку .m3u8 — сохраните её в mp4:
ffmpeg -i "<ссылка.m3u8>" -c copy assets/video/avatar.mp4
```

У Vivix лимит — одна генерация одновременно, поэтому запускайте по очереди. Постеры для видео: `ffmpeg -ss 1.5 -i assets/video/hero.mp4 -frames:v 1 assets/img/hero.jpg`.
