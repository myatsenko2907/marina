# Kape Apo AI Studio — демо для презентации курса «ИИ с нуля до про»

Страница на английском, которая на глазах у зала «собирает» кофейню **Kape Apo** в Давао (Филиппины): 8 ИИ-агентов делают бизнес-план, анализ локации, портреты клиентов, финмодель, бренд, меню, видео (Vivix), креативы, план запуска и чат-бота. Всё заготовлено заранее, поэтому показ не зависит от сети и ничего не сломается.

## Как показать (3 шага)

1. Откройте `index.html` в Chrome (двойной клик) и нажмите **F** — полный экран.
2. Нажмите **«Run the AI ✨»** (или Enter) — агенты отработают за ~12 секунд.
3. Листайте слайды стрелками **→ / ←** или кнопкой **▶ Autoplay**.

| Клавиша | Действие |
|---|---|
| Enter / Пробел | запустить ИИ-команду; во время анимации — пропустить её |
| → ← ↑ ↓ | следующий / предыдущий слайд |
| F | полный экран |
| R | начать заново |
| клик по видео | включить звук (бариста Мика говорит по-английски) |

Ссылка `index.html#results` сразу открывает готовые результаты без анимации.

## Слайды

1. **Business plan** — концепция «кофейня для ночной экономики Давао» (печатается на глазах), аудитория, SWOT.
2. **Location analysis** — 4 района Давао (Bajada, Poblacion, Matina, Lanang) по 5 факторам с весами: трафик, аренда, конкуренты, спрос ночных смен BPO, студенты. Схематичная карта, рейтинг, таблица сравнения и почему победил Bajada.
3. **Customer personas** — три портрета клиентов с цитатами и тем, как их привлечь.
4. **Financial model** — бюджет ₱2,6 млн, окупаемость, график на 24 месяца. Ползунки «средний чек» и «чеков в день» пересчитывают модель вживую.
5. **Brand** — логотип (гора Апо + кофейное зерно, рисуется анимацией), палитра, слоган, тон.
6. **Menu** — 12 позиций с местными вкусами (calamansi, Davao cacao, durian, ube) и маржой.
7. **Video** — 5 роликов, сгенерированных в Vivix: промо, рилс, говорящая бариста (A1), ферма на Mt. Apo, кофейня ночью.
8. **Creatives** — сторис, посты, баннер, 3 рекламных текста с A/B-прогнозом, контент-план, карточка для GrabFood/foodpanda.
9. **Launch plan** — план открытия на 90 дней (DTI, Mayor’s permit, BIR…), вакансия и вопросы для собеседования.
10. **AI barista** — чат-бот в телефоне: нажмите подсказку или задайте свой вопрос.
11. **Summary** — «с ИИ vs как раньше» и конфетти.

Цифры (аренда, трафик, бюджет) — правдоподобные оценки для учебного примера, не исследование рынка.

## Поменять тексты и цифры

Всё содержимое — в `data.js`: название, слоган, цены, меню, районы и их оценки, персоны, ответы бота, валюта (`currency`). Код трогать не нужно. Скорость анимации агентов — константа `STEP` в `app.js`.

## Живая генерация видео (необязательно, для «вау»)

```bash
VIVIX_API_KEY=ваш_ключ node server.mjs
# открыть http://localhost:3000
```

На слайде Video появится поле: впишите описание ролика (лучше по-английски) → «Generate live». Ролик 6 секунд, генерация обычно около минуты. Без ключа сервер тоже работает — просто без этого поля.

## Перегенерировать заготовленные видео

```bash
export VIVIX_API_KEY=ваш_ключ
node scripts/vivix.mjs world assets/video/hero.mp4 16:9 10 "описание ролика"
node scripts/vivix.mjs avatar /dev/null assets/img/barista.jpg "описание жестов" "Text the barista will say"
# avatar печатает ссылку .m3u8 — сохраните её в mp4:
ffmpeg -i "<ссылка.m3u8>" -c copy assets/video/avatar.mp4
```

У Vivix лимит — одна генерация одновременно, запускайте по очереди. Постер для видео: `ffmpeg -ss 1.5 -i assets/video/hero.mp4 -frames:v 1 assets/img/hero.jpg`.
