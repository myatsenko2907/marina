# Микро-сериалы: как держать зрителя

Полный плейбук с 116 источниками и пометками «вендор/самоотчёт»: `references/playbook.md` (копия `~/claud/hs-video/micro-series-playbook.md`). Ниже — рабочая выжимка. Когда пишешь или ревьюишь сериал, применяй её напрямую; за цифрами и цитатами ходи в плейбук.

## Три закона
1. **Держит открытый информационный разрыв, а не «интерес».** Вопрос серии должен быть назван явно (текст или реплика) и выглядеть закрываемым. Туманное «и тут всё изменилось» разрывом не является.
2. **Привязка наступает на 2–8 серии, не на пилоте** (Netflix). Планируй забег, а не ролик. Судить по 4–5-й серии, не по 2-й.
3. **Снять весь сезон до публикации первой серии; пауз между сериями нет.** Один пропущенный день снижает досмотр всех следующих серий.

## Формат
- Серия 45–90 с. Первая серия длиннее (до 2–3 мин): три сцены, три разворота, конфликт с первого кадра.
- Бесплатный сезон бренда: 5–8 серий. Не копировать 60–100 серий платных микродрам.
- Два–три постоянных героя с одной чертой и одной манерой речи. Симпатичный протагонист обязателен: без него нет саспенса. Злодей/герой архетипичны.
- Один конфликт на сцену, два человека, одно пространство. Без параллельных линий.
- Для комедии: одна «игра сцены» на сезон, каждая серия — ступень «ещё раз, но сильнее».

## Серия по секундам
| Время | Правило |
|---|---|
| 0–2 с | лицо в кадре |
| 0–3 с | суть конфликта; ни приветствия, ни логотипа, ни премисы |
| 3–6 с | 1–2 строки предвкушения концовки (последняя строка пишется до съёмки) |
| 2–3 с (со 2-й серии) | рекап = повтор последнего кадра прошлой серии, не пересказ |
| середина | два человека под давлением; **что-то меняется каждые 8–10 с**; биты связаны «но/поэтому», не «и потом» |
| спайк | раскрытие, переоценивающее увиденное; тест: «если без звука исчезает — это не спайк» |
| последние 5–10 с | вопрос, не ответ; резать на подъёме, на 2 с раньше «безопасного»; никакого аутро |

Расскажи «бомбу» и «часы» в первой серии, чтобы все следующие унаследовали саспенс (Хичкок). Настоящий сюрприз — один твист на сезон.

## Клиффхэнгер
- Сила по убыванию: раскрытие личности → переворот власти → инфо-крюк к давнему вопросу → физическая опасность (притупляется) → фальшивое напряжение (учит не доверять). Худшее: «далі буде» после сцены, где ничего не изменилось.
- Визуальный, не словесный; зритель может предположить ответ; обещает конкретную сцену.
- Чередовать типы (угроза, предательство, раскрытие, реверс, новое лицо, вызов к власти).
- Отыгрывается первой сценой следующей серии, до того как откроется больший вопрос.
- Ставить там, где давление пиковое, а не по формуле. Не оставлять героя в невозможной ситуации.
- Каждый открытый вопрос имеет известный авторам ответ. Долг развязки убивает доверие.
- Самый визуальный клифф — на 1-ю серию (продаёт сериал), самый сюжетный — на финал (продаёт следующий сезон), срединный твист — в 3–4-й. Финал закрывает вопрос сезона и в той же минуте открывает следующий.

## Диалог, монтаж, звук
- Реплика ≤ 8 слов, прямо, без подтекста и лекций; читать вслух со скроллом и резать то, что глаз пропускает. Читаемость — уровень 5-го класса.
- Крупные планы, без общих. Монтаж — «второе творение»: одни кадры, смонтированные иначе, дают другую конверсию.
- Музыка меняется на поворотах акцентом-ударом; SFX ниже диалога; не резать на каждом бите.
- Субтитры вшиты, 5–10 слов/с, цвет закреплён за говорящим на весь сериал; ничего важного в нижней четверти (ядро ≈ 900×1400 на 1080×1920). Джингл и стингер неизменны между сериями.

## Публикация
- «Part N/M» на экране и в описании; первая серия закреплена; плейлист с автоплеем (TikTok), сезоны/серии и related video (YouTube Shorts), закреплённый навигационный комментарий (IG).
- Серия в день в одно время; либо весь сезон сразу. Еженедельно — только реалити.
- Вторую серию публиковать ответом на топ-комментарий первой; рекап через stitch.
- Трейлер 15 с из клиффов за день до старта — главный верх воронки.
- Полированная драма идёт на YouTube, TikTok требует креаторской подачи. Мессенджеры — сопутствующий слой.
- Вместо «подпишись ради part 2» — вопрос зрителю. «Like for part 2» — штраф.
- Бренд: в био, не в кадре; продукт в ~40 % серий; «работает, если убрать, и не реклама, если оставить»; платное продвижение только после органических данных; KPI до запуска.

## Метрики
Skip rate до 3 с; viewed-vs-swiped 70–80 %+; удержание шорта 90 %+ чтобы взлететь; досмотр 2-й серии против одиночных роликов; доля просмотров от подписчиков; кривая спада по сериям (терять < 20 % между 1-й и 2-й). Смотреть кривую посекундно: провал = бит без изменения или длинная реплика.

## ИИ-производство
6–10 рефов на героя, цепочка портрет → первый кадр → движение; один voice ID на героя; голос и видео раздельно; на длинных репликах уходить с лица; реплики ≤ 2 предложений на план. Маркировка по правилам платформ. Зрители поощряют «не-ИИ» игру.

## Как использовать скилл
- **Написать сезон:** премиса в одну строку → герои → «бомба и часы» в 1-й серии → сначала клиффы всех серий по силе → карта пиков/спадов → биты «но/поэтому» по 8–10 с → диалог ≤ 8 слов → чек-лист.
- **Ревью готовой серии:** прогнать по чек-листу раздела 11 плейбука (20 пунктов), для каждого «нет» указать таймкод и правку.
- **План выпуска:** каденция, упаковка по платформам, трейлер, вопрос зрителю, KPI.
