# STEP Travel CRM — выездные лагеря

Отдельный дашборд для проверки Step2Travel: лиды по лагерям, обзвон, продажи ВЛ по филиалам, Meta-реклама и потери.

## Что внутри (`dist/index.html`)

| Вкладка | Что показывает |
|---|---|
| Обзор | KPI, лиды по странам и статусам, продажи ВЛ по странам и филиалам |
| Не позвонили / можно продать | Лиды без отказа и не фейк, с приоритетом обзвона, пометками менеджера и выгрузкой CSV |
| Все лиды | Все 503 лида Step2Travel с 01.04.2026: страна, статус, качество, комментарий, ссылка на карточку CRM |
| Продажи ВЛ по филиалам | Договоры формы «ВЛ» (выездной лагерь) по филиалам, странам, менеджерам и оплатам |
| Meta реклама | Кабинет `[ITS-AAA-travel_camps]`: расход, лиды, CPL по направлениям + качество этих лидов в CRM и продажи по стране |
| Instagram и потери | FB vs Instagram, воронка лид → договор, причины потерь, скорость обработки |

## Источники

- CRM `stt_ukr` (Step2Travel Ukraine) — интернет-заявки, режим history, с 01.04.2026.
- CRM договоры с формой обучения id 20 (`form_tc`, «ВЛ») — Киев, Днепр, Харьков полностью; остальные филиалы по счётчикам и частично.
- Meta Ads: кабинет `1785823405700372`, кампании с 01.04.2026, разбивка по площадкам и месяцам.

## Обновление

1. Выгрузить свежие JSON в `stt-crm/raw/` (имена файлов — см. `build.py`).
2. `python3 stt-crm/build.py` → `stt-crm/dist/index.html`.

`raw/` и `dist/` содержат персональные данные клиентов и в git не попадают. Паспорта, ИНН, e-mail и адреса в дашборд не выводятся.

## Ограничения

- Переписки Instagram Direct недоступны через подключённые инструменты — нужен доступ к Instagram Inbox.
- CRM не связывает лид Step2Travel с договором в филиале: связь ищется по ФИО (минимум имя + фамилия) и стране.
- Курс $/₴ не применяется: расход в $, выручка в ₴.
