# Tatak Prints AI Studio — вариант 4: печать на футболках в Давао

Готовое демо (как кофейня и аптека): 8 ИИ-агентов собирают студию печати на футболках **Tatak Prints** в Давао.

## Как показать

Откройте `index.html` в Chrome → **F** (полный экран) → **Enter** (запуск агентов) → стрелки **→ / ←**. `index.html#results` открывает результаты сразу.

2. **Location** — Poblacion, Matina, Bajada, Buhangin по 5 факторам; побеждает Poblacion рядом с Ateneo de Davao и UM.
3. **Customers** — Bea (студенческая организация), Carlo (HR в BPO), Tita Grace (семейная встреча).
4. **Financials** — бюджет ₱1,36 млн, ползунки «средний заказ» и «заказов в день».
5. **Brand** — Tatak Prints, палитра CMYK, логотип-футболка.
6. **Products** — 12 позиций: DTF, шелкография, пакет для организаций, Kadayawan, худи, кепки, услуги.
7. **Video** — 3 ролика Vivix: термопресс, шелкография, владелец Jun говорит на камеру.
8. **15-second TV ad** — ролик Vivix W1 с раскадровкой и плашкой бренда.
9. **Creatives** — посты, A/B-реклама, контент-план, карточка Shopee.

12. **Summary**.
