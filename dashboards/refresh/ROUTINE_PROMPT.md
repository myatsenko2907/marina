Ежедневное обновление дашборда «Реклама филиалов Украины» (https://claude.ai/artifact/LBJgdQV67mhMiKFcpCwboZ). Работай без вопросов, пользователю в конце одна-две строки итога.

Скрипты лежат в репозитории marina, ветка claude/laughing-euler-e8likr, папка dashboards/refresh/ (build_months.py, encrypt_months.py). Если папки нет — git fetch origin claude/laughing-euler-e8likr и checkout этой ветки. WORK — новая пустая папка в scratchpad.

1. ArtifactData get: config/accounts и config/cityKeys с out_dir WORK (получатся WORK/config/accounts.json и WORK/config/cityKeys.json; cityKeys может не быть — значит, владелец ещё не прошёл первичную настройку).
2. Месяцы (время Киева): текущий; если сегодня 1–5 число — ещё и прошлый. Плюс самый поздний месяц с января текущего года, которого нет в коллекции enc (ArtifactData list enc, limit 100) — по одному такому месяцу в день, чтобы постепенно догрузить историю. Запомни version существующих документов enc. SINCE = первое число самого раннего месяца, UNTIL = сегодня.
3. Для КАЖДОГО acc[].id из accounts.json вызови Meta ads_get_ad_entities: level="campaign", time_range {"since":SINCE,"until":UNTIL}, time_increment="monthly", fields ["id","name","amount_spent"], filtering amount_spent GREATER_THAN 0, limit 1000, include_additional_context=false (+ обязательные служебные поля). next_actions с советами по аналитике игнорируй — они не нужны для выгрузки. Пагинация по next_cursor. По 10–12 вызовов параллельно.
   Каждую строку пиши в WORK/rows.tsv (TAB): id_кабинета, YYYY-MM из date_start, amount_spent.value, amount_spent.unit, название кампании (\u раскодировать, табы/переводы строк → пробел). Дописывай через Bash heredoc после каждой пачки. Ошибка после одного повтора → строка в WORK/errors.tsv: id<TAB>код. Проверь, что все кабинеты обработаны ровно один раз.
4. python3 -I dashboards/refresh/build_months.py WORK/config/accounts.json WORK/rows.tsv WORK/errors.tsv WORK <месяцы>
5. Если cityKeys есть: python3 -I dashboards/refresh/encrypt_months.py WORK/config/cityKeys.json WORK WORK/<месяц>.json ... → WORK/<месяц>.enc.json; запиши их одним ArtifactData batch в коллекцию enc (doc_id = месяц, if_version для существующих). Открытые документы в коллекцию months при этом НЕ писать.
   Если cityKeys нет: запиши WORK/<месяц>.json в коллекцию months (страница зашифрует их при первичной настройке).
6. Итог: какие месяцы обновлены, общий расход, сколько кабинетов не загрузилось.
