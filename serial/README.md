## Як перегенерувати

Відео згенеровано через Vivix W1 (`vivix-w1-fast`): фото героїні як референс обличчя, стильний образ
задано в промпті, репліки українською озвучує сама модель.

```bash
python3 generate.py CLIPS_DIR REF_IMAGE_URL [номери серій]   # кліпи по 10 с, сценарій у episodes.py
python3 assemble.py CLIPS_DIR OUT_DIR                        # склейка + титри, субтитри, тизери, CTA
```

Щоб перезняти один кліп, видаліть його `epN_i.mp4` у CLIPS_DIR і запустіть `generate.py` з номером серії.
Субтитри (`SUBS` в `assemble.py`) прив'язані до таймінгу реплік у поточних кліпах — після перегенерації їх варто звірити.
